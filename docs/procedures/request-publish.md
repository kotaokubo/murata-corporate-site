# 手順書：本番への公開を依頼する

前提：作業ブランチを `staging` へ入れ、検証用の URL で、事務の方と公開判断者が確かめ終わっていること。

1. **同じ作業ブランチから** `main` へ PR を出す（`staging` から出さない）
2. PR テンプレートの「確かめたこと」と「公開を判断した人」を埋める
3. 必須チェックの「staging-verified」が失敗したら、検証のあとに直しを足したのに `staging` へ入れ直していない。もう一度 `staging` へ PR を出して確かめてもらう
4. マージは大久保が行う。事務の方と AI はマージしない
